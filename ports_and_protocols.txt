# Ports and Protocols

# TCP

How does TCP work?
  SYN -> SYN-ACK -> ACK

Characteristics:
  - Connection-oriented (3-way handshake)
  - Reliable delivery
  - Error checking
  - Packet ordering
  - Retransmits lost packets
  - Slightly slower than UDP

E.g.
HTTP/HTTPS
SSH
SMB
LDAP
RDP
FTP
SMTP

# UDP

How does UDP work?
  Sends without establishing a connection.

Characteristics:
  - Connectionless
  - No acknowledgements
  - No retransmissions
  - Faster than TCP
  - Lower overhead

E.g.
DNS queries
DHCP
SNMP
TFTP
NTP
VoIP
Video streaming
